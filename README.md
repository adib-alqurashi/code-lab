# Code Lab

Where I write code: problem solving, language practice, data science notebooks and small projects.

| Folder | What goes there |
| --- | --- |
| [problem-solving](problem-solving/) | LeetCode, Codeforces and Kaggle-style exercises, one file per problem |
| [python](python/) | Python practice: language features, standard library, idioms |
| [java](java/) | Java practice: OOP, data structures, algorithms |
| [data-science](data-science/) | Jupyter notebooks: NumPy, pandas, Matplotlib, scikit-learn, and [Kaggle](data-science/kaggle/) work |
| [projects](projects/) | Small complete projects, each in its own folder with a README |

## Conventions

- Problems: `problem-solving/<platform>/<number>-<slug>.<ext>`, for example `leetcode/0001-two-sum.py`.
  The first lines of each file give the link, the idea and the time/space complexity.
- Notebooks: run top to bottom with no errors before committing, and keep outputs small.
- Projects: each has a README with what it does, how to run it and what I learned.
